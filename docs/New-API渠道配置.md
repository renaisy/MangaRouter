# New-API 渠道配置详解（智能路由落地）

> 这份文档讲清楚：**怎么在 New-API 后台把"选便宜渠道"这件事配出来。**  
> 快速路径：技术负责人可用 [`管理员配置手册.md`](./管理员配置手册.md) 的 **模板向导**一键创建三档渠道；下文为完整后台手工步骤。

---

## 一、核心概念：分组 = 路由钥匙

New-API 的「分组（Group）」是把多个渠道打包在一起的逻辑集合。
调用时带上分组名，New-API 就只在对应分组里挑渠道（按权重负载均衡）。

我们设三个分组，对应三种重要级：

```
draft 组    ← 草稿镜头（Seedance mini + 第三方聚合）
standard 组 ← 日常镜头（Seedance fast）
final 组    ← 成片镜头（Seedance 2.0 / 2.5 官方）
```

---

## 二、配置步骤

### 第 1 步：添加渠道（「渠道」→「添加渠道」）

为每个 Seedance 来源单独建一个渠道。下表是推荐配置：

| 渠道名（自定义） | 类型 | Base URL | 密钥 | 模型 | 分组 | 权重 | 优先级 |
|----------------|------|----------|------|------|------|------|--------|
| 火山-mini | Volcengine | 方舟默认 | 方舟 API Key | doubao-seedance-2-0-mini | draft | 100 | 1 |
| 聚合A-mini | OpenAI | 聚合商地址 | 聚合商 Key | （聚合商支持的mini模型名） | draft | 30 | 5 |
| 火山-fast | Volcengine | 方舟默认 | 方舟 API Key | doubao-seedance-2-0-fast | standard | 100 | 1 |
| 聚合A-fast | OpenAI | 聚合商地址 | 聚合商 Key | 对应模型名 | standard | 40 | 5 |
| 火山-2.0 | Volcengine | 方舟默认 | 方舟 API Key | doubao-seedance-2-0 | final | 100 | 1 |
| 火山-2.5 | Volcengine | 方舟默认 | 方舟 API Key | doubao-seedance-2-5-pro | final | 90 | 2 |

**字段说明：**
- **类型**：New-API 若已内置 `Volcengine` 适配就选它；否则选 `OpenAI`
  - 选 OpenAI 时，Base URL 填方舟兼容地址；如 New-API 不支持 Seedance 异步，Base URL 填**适配器地址** `http://localhost:18008`
- **分组**：必须严格用 `draft` / `standard` / `final` 这三个名字（提交工具靠它路由）
- **权重**：同组内数字越大越优先用；官方高权重，聚合渠道低权重兜底
- **优先级**：数字小者优先；同模型多渠道时控制先后

### 第 2 步：逐个测试渠道
渠道列表每行有「测试」按钮，点一下确认能通。失败常见原因：
- API Key 错误 / 未开通对应模型 → 去火山控制台检查
- Base URL 错误 → 确认地区（北京区 `ark.cn-beijing.volces.com`）
- New-API 未支持 Seedance 异步 → 改填适配器地址（见部署指南第 7 节）

### 第 3 步：创建令牌并分组绑定
1. 「令牌」→「添加令牌」
2. 命名（如「全员-提交」或按人「张三」）
3. **关键**：在「分组」或「允许的分组」里勾选 `draft,standard,final` 三个
   - 这样这个令牌才能按重要级路由到对应分组
   - 若想限制某人只能用便宜档，只勾 `draft`
4. 可设「额度」做月度预算（如每人 500 元）
5. 保存后复制令牌字符串，发给对应成员

## 三、路由是怎么生效的

提交工具调用时，会根据 NocoDB 里镜头的 `Priority` 字段，在请求里带上对应分组：

| 镜头 Priority | 提交工具带的分组 | New-API 行为 |
|--------------|----------------|-------------|
| 草稿 | `draft` | 在 draft 组里按权重挑（火山-mini 优先，聚合兜底） |
| 日常 | `standard` | 在 standard 组里挑（火山-fast 优先） |
| 成片 | `final` | 在 final 组里挑（火山-2.0 优先，2.5 备用） |

**失败自动切换**：New-API 默认在渠道失败时按优先级切到同组下一个渠道。
确保每组至少有 2 个渠道，避免单点故障。

## 四、成本控制建议

### 1. 按人设额度
「令牌」里给每人设月度额度，超了自动停，防失控。

### 2. 按项目分组（进阶）
项目 A 预算紧张？新建一个渠道分组 `projectA-draft`，只用最便宜的聚合渠道，
让该项目成员的令牌绑定这个组。

### 3. 每周调权重
在「日志」页按渠道看上周的：
- **成功率**：低于 95% 的降权重或禁用
- **实际单价**：对比官方与聚合，谁便宜提谁权重
- **平均耗时**：太慢的渠道降权（除非特别便宜）

### 4. 利用限时折扣
火山常有限时折扣（如 fast 版 75 折），折扣期间把对应渠道权重调高。
关注火山引擎「模型价格」页：https://docs.volcengine.com/docs/82379/1544106

## 五、各 Seedance 版本参考（2026-08）

## 六、排错速查

| 现象 | 可能原因 | 解决 |
|------|---------|------|
| 提交报 401 | 令牌无效或额度用完 | 检查令牌、额度 |
| 报「无可用渠道」 | 分组名拼错或令牌未绑定该组 | 确认分组名是 draft/standard/final |
| 一直 running | 模型排队或轮询超时 | 看适配器日志；适当调大 POLL_MAX_SECONDS |
| 成功但没视频 | video_url 过期或下载失败 | 检查 MinIO 连接；成片有时效需及时归档 |
| 质量不稳定 | 聚合渠道质量波动 | 关键镜头调高官方渠道权重/优先级 |
