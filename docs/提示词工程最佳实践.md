# Seedance 提示词工程最佳实践（漫剧专用）

> 面向编剧、分镜师、ComfyUI 专家。
> 目标：用更少的调用次数（省钱）写出更准的提示词（少返工）。
> 这些经验应沉淀回 NocoDB 的提示词模板库，全员复用。

---

## 一、核心心法：结构化六要素

漫剧镜头的提示词不要写成一坨散文。按下面**六个要素**的结构写，AI 理解更准：

```
[主体] + [动作] + [环境] + [镜头] + [光影/氛围] + [风格]
```

| 要素 | 作用 | 漫剧示例 |
|------|------|---------|
| **主体** | 画面核心是谁/什么 | 少女、机甲、黑猫 |
| **动作** | 在做什么（动态关键） | 回头、奔跑、抬手施法 |
| **环境** | 在哪 | 樱花树下、废墟都市、星河 |
| **镜头** | 景别+运镜 | 特写、全景、缓慢推进、环绕 |
| **光影/氛围** | 情绪基调 | 逆光、霓虹、温暖夕阳、压抑阴雨 |
| **风格** | 整体观感 | 日系动漫、赛博朋克、水墨、写实电影感 |

**完整示例（好）**：
> 少女（主体）在樱花树下（环境）抬头伸手接落花（动作），特写镜头缓慢推向她的眼睛（镜头），逆光柔焦温暖色调（光影），日系动漫风格（风格）

**反面示例（差，别这么写）**：
> 一个漂亮的女生在很美的地方看花
> （没有景别、没有运镜、没有风格，AI 自由发挥导致结果不可控）

## 二、景别与运镜词表（直接抄）

Seedance 对这些镜头术语理解很好，**用专业词比用描述词效果好**：

### 景别
`大远景` `远景` `全景` `中景` `近景` `特写` `大特写`

### 运镜（动态镜头必填，否则画面会"发呆"）
| 词 | 效果 | 适合场景 |
|----|------|---------|
| 推进 push in | 镜头向主体靠近 | 强调情绪、揭示 |
| 拉出 pull out | 远离主体 | 揭示环境、收尾 |
| 环绕 orbit | 绕主体转 | 展示角色全貌、纪念碑感 |
| 平移 pan | 水平移动 | 展现场景、跟拍 |
| 升降 tilt up/down | 垂直 | 仰视威严、俯视渺小 |
| 跟拍 tracking | 跟随主体 | 奔跑、追逐 |
| 手持 handheld | 轻微晃动 | 紧张、纪实感 |
| 慢动作 slow motion | 降速 | 戏剧高潮、唯美 |
| 静止 static | 不动 | 适合首尾帧控制 |

> 💡 **漫剧黄金法则**：每个动态镜头至少指定一个运镜词。不指定运镜，Seedance 会随机选，导致同一提示词每次结果差异大。

## 三、四种输入模式的提示词策略

### 模式 1：文生视频（无图）
提示词要**最详细**，因为没有任何视觉锚点：
> 全部六要素都写满，景别和运镜必须明确

### 模式 2：首帧图生视频（1 张首帧）
首帧已提供视觉，提示词**重点是动作和运镜**：
> ✅「从首帧姿态开始，少女缓缓转头望向天空，镜头轻微推进，风吹动发丝」
> ❌ 不要重复描述首帧已有的外貌/服装（图里已经有）

### 模式 3：首尾帧（控制力最强）
提示词**描述中间的过渡**，不必描述首尾帧本身：
> ✅「从首帧的白天平滑过渡到尾帧的夜晚，光影从暖橙变冷蓝，云层流动加速，镜头缓慢推进」
> 关键：讲清"怎么变化"，让 AI 补好中间帧

### 模式 4：多参考图（角色/场景一致性）
提示词**描述主体如何行动**，参考图提供外貌/场景：
> ✅「参考图中的角色在参考图的街道上奔跑，转身回望，手持参考图中的道具」
> 多张参考图按"角色图 + 场景图 + 道具图"组合，提示词把它们关联起来

## 四、省钱的提示词技巧

每次返工都是真金白银。下面技巧帮你**一次成片**：

### 1. 用草稿档迭代（最重要）
- 先用 `草稿`(Seedance mini，~0.5元/秒) 跑 3-5 版调提示词
- 满意后再用 `成片`(Seedance 2.0，~1元/秒) 出最终版
- **不要直接拿成片档试错**——这是最大的浪费

### 2. 固定 seed 复现
同一提示词 + 同一 seed = 几乎相同结果。微调提示词时**保持 seed 不变**，
就能看清"改了哪个词带来什么变化"，避免盲目试错。
（适配器支持 `seed` 参数，提交工具可指定）

### 3. 反向提示词排雷
如果总出现不想要的元素（如"多余的手指""变形的背景"），
把这些**反义词**也写进提示词区域附近，或用负面描述规避：
> 「手部清晰完整、五根手指」（正面强化比单纯否定更有效）

### 4. 沉淀模板库
成功的提示词存进 NocoDB，按场景分类：
- 角色登场镜头模板
- 战斗动作模板
- 环境空镜模板
- 情绪特写模板

下次类似镜头**改主体名词即可**，省去重新摸索。

## 五、漫剧常见场景提示词模板

### 场景 A：角色登场（首帧图 + 推进）
```
[首帧：角色站立全身图]
从首帧开始，镜头从脚部缓慢上摇至面部特写，微风吹动衣摆和发丝，
逆光边缘发金光，[日系动漫/写实]风格，电影感
```

### 场景 B：情绪特写（文生 + 慢动作）
```
少女面部大特写，眼眶含泪，一滴泪缓缓滑落脸颊，慢动作，
镜头静止，柔和侧光，背景虚化为光斑，细腻皮肤质感，[风格]
```

### 场景 C：动作戏（首尾帧 + 快节奏）
```
[首帧：角色起手姿势] [尾帧：角色出招结束姿势]
从首帧到尾帧快速过渡，角色挥剑斩击，剑光拖出弧线，
镜头快速横移跟拍，尘土飞扬，冷色调，[风格]
```

### 场景 D：环境空镜（文生 + 升降）
```
赛博朋克城市夜景大远景，镜头缓慢上升越过摩天楼顶，
霓虹招牌闪烁，飞行器穿梭，雨幕，湿润反射的街道，电影感，[风格]
```

### 场景 E：角色一致性连续镜头（多参考图）
```
[参考图1：角色设定图] [参考图2：场景设定图]
参考图中的角色在参考图的场景中沿街道奔跑，转身回望，
手持发光道具，镜头跟拍，动态模糊，[风格]
```

## 六、质量不稳时的排查清单

| 现象 | 可能原因 | 调整 |
|------|---------|------|
| 角色变形/多肢 | 参考图不够清晰或多张冲突 | 减少参考图数量；用更高清的角色图 |
| 动作僵硬/像PPT | 缺运镜词或动作描述太复杂 | 每镜头只指定 1 个主运镜；动作要具体 |
| 风格不统一 | 提示词没写风格，或风格词冲突 | 固定一个风格词；建立本剧统一风格词 |
| 和分镜稿对不上 | 首尾帧与提示词动作矛盾 | 首尾帧的姿态要和提示词动作连贯 |
| 画面发空/没主体 | 主体描述模糊 | 主体放句首，用具体名词 |
| 时长不够 | 单次生成有秒数上限 | 用 Seedance 2.5 的 30 秒直出，或多段拼接 |

## 七、团队协作约定

1. **成功的提示词必须入库**：在 NocoDB 建一张"提示词模板表"，字段：场景类型、提示词、所用模型、seed、效果评分、缩略图
2. **失败案例也记录**：在备注里写"为什么失败"，避免同事踩同样的坑
3. **统一风格词**：本剧开拍前，全组商定 1-2 个固定风格词（如"日系赛博动漫风"），所有镜头都用，保证全片统一
4. **分镜评审带提示词**：分镜会不只看构图，也要评审提示词是否完整（六要素是否齐）

## 八、给 ComfyUI 专家的额外建议

专家在做工作流模板时，可以把提示词拆成**可复用变量**：
- `{{character}}` 角色名（关联 Group ID）
- `{{action}}` 动作短语
- `{{scene}}` 场景短语
- `{{shot}}` 景别运镜
- `{{style}}` 风格（全局固定）

工作流里拼接成完整提示词。这样成员填表时只填碎片，专家在模板里控制结构和风格统一性。
