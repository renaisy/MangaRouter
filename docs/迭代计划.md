# 迭代计划与优化方向（PDCA）

> 主部署：**腾讯云 VPS + Caddy HTTPS**。  
> 每轮：Plan → Do → Check → Act。本文件为真相源。  
> 目标：分散办公漫剧团队完成「分档路由提交 → 异步出片 → 归档协作 → 成本可见」，并具备首尾帧/多参考等高级能力。

---

## 能力盘点（v0.5.0+）

| 能力域 | 成熟度 |
|--------|--------|
| VPS / HTTPS / basicauth（submit/dash/admin） | ✅ 生产基线（须填真实哈希） |
| New-API 路由 + admin-tool | ✅ |
| 异步提交 + worker 归档 | ✅ |
| 公网预签名图传 / adapter 鉴权 / 成本 | ✅ |

| 指纹缓存 / 定时批量窗口 / 结构化日志 | ✅ C8 |
| SSO / 多供应商抽象 | ⏳ C9+ 后置 |

## 已完成轮次（归档）

### C1–C4（至 v0.4.x）
- VPS 基线、协作闭环、异步 worker、工程质量与安全热修、admin-tool（v0.4.2）

### C5 v0.5.0 — 上线硬化与运营闭环
- Do：MinIO 业务用户变量与初始化；`deploy/smoke-check.sh`；成片档令牌运营说明；Caddy IP allow 注释模板
- Check：smoke-check + pytest + compose config
- Act：公网上线清单可勾选；安全残留部分关闭

### C6 v0.6.0 — ComfyUI 生产化
- Do：提交前剥离模板元数据；成片归档 MinIO + NocoDB；bridge 单测；手册 Day6 归档验收
- Check：mock pytest；人工真实模板可选
- Act：专业模式进入协作闭环（内容仍依赖专家 API JSON）

### C7 v0.7.0 — 多剧隔离
- Do：`projects/{ProjectKey}/` 强制前缀；submit 必填 ProjectKey；看板/批量按 ProjectKey 过滤
- Check：前缀单测；交叉不可串前缀
- Act：多剧基础策略就绪

### C8 v0.8.0 — 效率与可观测
- Do：提交指纹缓存；worker 定时窗口；worker/adapter 结构化日志与失败计数
- Check：缓存命中单测；窗口外不跑
- Act：本季主线收口；架构项进 C9+

---

## 执行约定

1. 每轮单独版本 bump + CHANGELOG；禁止跨轮大杂烩
2. Check 门禁：对应模块 pytest + `docker compose config` + `deploy/smoke-check.sh`
3. ComfyUI：无专家真实 API JSON 不宣称「模板开箱即用」
4. 不扩大「自建密钥库」范围

---

## 版本节奏

- 补丁：热修与文档
- 次版本：闭环能力（C5–C8）
- 主版本：架构级（C9+）
