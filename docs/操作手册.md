# 操作手册（团队成员必读）

> 🎬 给编剧、分镜师、审核、制片等**所有团队成员**。
> 全程只用浏览器（HTTPS 域名），**不用装 ZeroTier、不用敲命令**。

---

## 一、首次准备（每人做一次，约 2 分钟）

找技术负责人要：
- 🔗 **协作平台**：`https://collab.你的域名`
- 🔗 **提交工具**：`https://submit.你的域名`
- 🔗 **成本看板**（制片）：`https://dash.你的域名`
- 🔑 **你的 New-API 令牌**（提交视频时用；多数情况已由管理员配进服务器，你只需登录协作平台）

用负责人开通的账号登录协作平台即可。

---

## 二、日常工作流程

### 角色 A：编剧 / 分镜师

#### 1. 填写分镜
打开协作平台 → **Storyboards**，新增行：

| 字段 | 怎么填 |
|------|--------|
| **Prompt** ⭐ | 镜头描述 |
| Project / Episode / ShotNo | 剧名 / 集 / 镜头号 |
| **Priority** ⭐ | 草稿 / 日常 / 成片（决定成本档） |
| ImageUrl | 可选，已有公网图 URL 时填 |
| **Status** | 必须为 **`pending`** |

#### 2. 图片模式（可选）
在提交工具「标准提交」也可直接上传首帧/尾帧/参考图（自动进 MinIO 并生成方舟可拉的预签名链接）。

| 上传 | 效果 |
|------|------|
| 不传 | 文生视频 |
| 首帧 | 图生视频起点 |
| 首帧+尾帧 | 运镜控制最稳 |
| 多参考图 | 角色/风格参照 |

#### 3. 批量提交
1. 打开 **提交工具** → 「NocoDB 批量提交」
2. 刷新 pending → 勾选 → **批量异步提交**
3. 页面很快返回；**不要**以为卡住——后台 worker 在跑

#### 4. 查看结果
回 Storyboards：
- `Status=succeeded`：看 `ShareUrl`（约 7 天有效）或 `VideoUrl` / `MinioPath`
- `Status=failed`：看 `ErrorMsg`
- `Status=running`：生成中，稍后再刷

> 成片会归档到 MinIO `outputs/`；方舟直链有时效，以 MinIO / ShareUrl 为准。

#### 重要级与费用

| 档 | 用途 | 约价 |
|----|------|------|
| 草稿 | 试提示词 | ~0.5 元/秒 |
| 日常 | 主力 | ~0.7 元/秒 |
| 成片 | 交付 | ~1 元/秒 |

先草稿调通，再成片，省钱。

#### ComfyUI 专业模式
专家模板就绪后：提交工具切「ComfyUI 专业模式」→ 选模板 → 填参。无需学节点。

---

### 角色 B：审核
1. 筛选 `Status=succeeded`
2. 打开 `ShareUrl` 或 `VideoUrl` 观看
3. 填 `Review` / `ReviewStatus`（通过 / 打回）
4. 打回时把 `Status` 改回 `pending` 方便重提

若配置了飞书/钉钉 webhook，成片归档后审核人会收到通知。

---

### 角色 C：制片
- **Projects** 表管进度与预算
- **Costs** / 成本看板看花费与三档占比
- MinIO 控制台（`https://minio.域名`）看 `outputs` 桶（账号问负责人）

---

## 三、常见问题

| 现象 | 处理 |
|------|------|
| 一直 running | 等几分钟；仍不动联系负责人查 `submit-worker` 日志 |
| 提交 401 | 令牌失效或额度用尽 |
| 有图失败 | 多半是公网 MinIO（s3 域名）未通，找负责人 |
| ShareUrl 过期 | 用 MinIO 控制台重新下载或让负责人重签 |

---

## 四、流程一览

```
写分镜(pending) → 批量/单条异步提交(running+TaskId)
       → worker 轮询成功 → 归档 MinIO → 回填 ShareUrl
       → 审核 → 通过/打回
```
