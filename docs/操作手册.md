# 操作手册（团队成员必读）

> 🎬 给编剧、分镜师、审核、制片等**所有团队成员**。
> 全程只用浏览器，**不用装软件、不用敲命令**。

---

## 一、首次准备（每人做一次，约 5 分钟）

### 1. 加入团队虚拟网络
1. 找技术负责人要 **ZeroTier 网络 ID**（16 位数字）
2. 下载安装客户端：https://www.zerotier.com/download/
   - Windows：下载 `.exe` 一路下一步
   - Mac：下载 `.dmg` 拖到 Applications
3. 打开客户端（电脑右下角/顶部菜单栏会出现图标）：
   - 右键图标 → `Join Network`（加入网络）
   - 粘贴网络 ID → 确认
4. 通知负责人「我已加入，请授权」，等他授权后图标会变成绿色 ✓

### 2. 收集访问信息
找技术负责人要这三样，记在便签上：
- 🔗 **团队网址**：`http://<负责人告诉你的IP>:18080`（协作平台）
- 🔗 **提交工具**：`http://<负责人告诉你的IP>:18501`
- 🔑 **你的令牌**：一串字符，提交视频时用

## 二、日常工作流程

### 角色 A：编剧 / 分镜师（写提示词、提交生成）

#### 第 1 步：登录协作平台
浏览器打开 **团队网址**（:18080），用账号登录。

#### 第 2 步：填写分镜
点开 **Storyboards（分镜表）**，点「+ 新增行」，填这些：

| 字段 | 怎么填 | 例子 |
|------|--------|------|
| **Prompt 提示词** ⭐ | 用中文或英文描述这个镜头 | 「特写：少女低头，樱花落在发间，柔光，电影感，慢动作」 |
| Project 项目 | 剧名 | 《星河恋人》 |
| Episode 集 | 第几集 | S01E03 |
| ShotNo 镜头号 | 自己编号 | S01E03-L012 |
| **Priority 重要级** ⭐ | 选一个，决定用哪个档次的模型 | 见下表 |
| ImageUrl 参考图URL | 图生视频时填图片链接 | （可选） |
| **Status 状态** | **必须填 `pending`**，否则提交工具看不到 | pending |

#### 第 2.5 步（可选）：要不要传参考图 / 首尾帧？

如果这个镜头需要"以某张图开头"、"以某张图结尾"、或"参照某几张图的角色/场景"，
在提交工具的「输入图片」区域上传：

| 你上传什么 | 效果 | 适合 |
|-----------|------|------|
| 不传 | 文生视频（纯文字描述生成） | 从零构思的镜头 |
| 只传**首帧** | 视频从这张图开始，往后生成动态 | 已有静帧/分镜稿，让它动起来 |
| 传**首帧+尾帧** | 起点和终点都固定，AI 补中间过渡 | **运镜控制最准**，漫剧最常用 |
| 传**多张参考图** | 参照图里的角色/场景/风格生成 | 角色一致性、场景复用、风格统一 |

> 💡 **首尾帧是控制力最强的模式**：漫剧里同一个动作的不同机位，
> 用首尾帧能让镜头衔接顺滑。建议关键镜头都走首尾帧。
>
> 参考图会自动上传到素材库（MinIO）再提交，你不用管链接。

#### 高级能力：ComfyUI 专业模式（角色一致性等）

对于"同一角色在几十个镜头里必须长得一样"这种需求，单靠参考图不够稳定。
团队会用 **ComfyUI 专业模式**：
1. 内部专家用 ComfyUI 给每个主要角色建立"角色资产"（Group ID）
2. 把工作流做成模板放进系统
3. 你在提交工具切到「ComfyUI 专业模式」→ 选模板 → 填提示词和角色 ID → 触发
4. 效果：生成的角色外貌高度一致

> 这部分**不需要你学 ComfyUI**，专家会把模板做好，你只管填表。详见内部专家。

#### ⭐ 重要级怎么选（直接关系到成本和质量）

| 选什么 | 含义 | 用在哪 | 大概花费 |
|--------|------|--------|---------|
| 🟢 **草稿** | 最便宜，快速试效果 | 写好提示词先试一版看构图/动作对不对 | ~0.5 元/秒 |
| 🟡 **日常** | 性价比主力 | 草稿满意后，出可看的版本 | ~0.7 元/秒 |
| 🔴 **成片** | 质量最高 | 最终要交付的高质量镜头 | ~1 元/秒 |

> 💡 **省钱诀窍**：先用「草稿」反复调提示词，满意了再用「成片」出最终版。同一个镜头别反复用「成片」烧钱。

#### 第 3 步：批量提交生成
1. 浏览器打开 **提交工具**（:18501）
2. 左侧填好：
   - New-API 令牌 = 负责人给你的那串
   - 「分镜表 ID」= 负责人告诉你的 Storyboards 表 ID
3. 点 **🔄 刷新待提交分镜**
4. 勾选你要提交的镜头（或全选）
5. 点 **🚀 批量提交所选分镜**
6. 等进度条走完（每个镜头约 1-3 分钟）

#### 第 4 步：查看结果
- 提交完后，回协作平台的 Storyboards 表
- `Status` 会变成 `succeeded`，`VideoUrl` 有链接，`MinioPath` 有存档路径
- 点 VideoUrl 链接直接看视频
- 成片也已自动存到素材库（MinIO）

---

### 角色 B：审核（看成片、给意见）

1. 登录协作平台，打开 **Storyboards 表**
2. 筛选 `Status = succeeded` 的行（这些是已生成的）
3. 点 `VideoUrl` 链接观看
4. 在 `Review 审核意见` 写修改建议
5. `ReviewStatus 审核状态` 改为：
   - ✅ **通过** → 可以用了
   - ❌ **打回** → 在 Review 里写清要改什么，把 `Status` 改回 `pending`，编剧改完提示词后重新提交

---

### 角色 C：制片 / 项目管理

#### 管项目
- 在 **Projects 表** 维护各剧的进度、负责人、预算
- 在 **Costs 表**（每周从技术负责人那要数据）跟踪花了多少钱

#### 看素材库
- 浏览器打开 **MinIO 控制台**（地址问技术负责人，一般是 :19001）
- 用负责人给的账号登录
- `outputs` 桶里按 `剧名/集/镜头号` 存放着所有成片，可下载

## 三、常见问题

**Q：提交工具提示「读取 NocoDB 失败」？**
A：检查①ZeroTier 是否连上（图标绿色）②令牌对不对③分镜表 ID 对不对。

**Q：状态一直是 running 不变？**
A：视频生成需要时间，5 分钟内正常。超过 15 分钟请联系技术负责人查日志。

**Q：生成失败了怎么办？**
A：在 Storyboards 表的 Remark 字段看错误原因。常见是提示词太长或参考图链接失效，修改后把 Status 改回 `pending` 重新提交。

**Q：怎么调整重要级省钱？**
A：80% 的迭代用「草稿」，只在最终版用「成片」。一个镜头反复生成时，前面都走「草稿」。

**Q：我在外面/出差能用吗？**
A：能。只要有网络，ZeroTier 连上团队网络就能访问，跟在办公室一样。

## 四、一图速记

```
写提示词(协作平台) → 标 pending + 选重要级
        ↓
   提交工具 → 批量提交
        ↓
   自动生成(草稿最便宜/成片最贵)
        ↓
   自动回填状态+链接+存档
        ↓
   审核看片 → 通过/打回改
```

有任何问题，先看本手册，再问技术负责人。祝出片顺利！🎉
