# 管理员配置手册（admin-tool）

> 面向技术负责人：用简化 Streamlit 页管理 New-API **渠道**与**令牌**。  
> 密钥仍只存于 New-API，本服务不落盘、不写 NocoDB。

---

## 何时用 admin-tool vs 完整 New-API 后台

| 场景 | 建议入口 |
|------|----------|
| 一键建漫剧三档渠道（draft/standard/final） | **admin-tool**（模板向导） |
| 改上游 Key、Base URL、权重、启用/禁用 | **admin-tool** |
| 创建团队用令牌并绑定分组 | **admin-tool**（简管） |
| 计费倍率、模型映射、复杂渠道类型、用户权限 | **New-API 完整后台** `api.your.domain` |

admin-tool **不替代** New-API；复杂能力请直接打开 New-API。

---

## 部署与访问

1. `.env` 填写（见 `.env.example`）：
   - `ADMIN_NEWAPI_TOKEN`：在 New-API **个人设置**生成的**系统 access_token**（不是业务 `sk-` 转发令牌）
   - `ADMIN_NEWAPI_USER_ID`：该用户数字 ID（root 多为 `1`）
   - `ADMIN_PORT`：默认 `18503`（仅本机回环）
2. `docker compose up -d admin-tool`
3. Caddy：`admin.your.domain` → `127.0.0.1:18503`，**必须** `basicauth`，用户建议用 `admin`（与 submit/dash 的 `team` **分开**）

```bash
caddy hash-password   # 为 admin 用户生成哈希，写入 deploy/Caddyfile
curl -I https://admin.your.domain   # 无凭证应 401
```

## 页面功能

1. **渠道一览**：列表；测试连通、启用/禁用、删除（删除需二次输入渠道名）
2. **添加渠道**：字段对齐 New-API（name / type / key / base_url / models / group / weight / priority）
3. **模板向导**：按 [`New-API渠道配置.md`](./New-API渠道配置.md) 批量创建火山 mini/fast/2.0（可选聚合、可选走 `http://seedance-adapter:18008`）
4. **令牌管理**：创建绑定分组与额度；**仅新建时展示一次完整 key**，列表不回显已有密钥

分组：模板强制 `draft|standard|final`；高级自定义会警告「submit-tool 默认不认识」。

**成片档运营（缓解 Priority→成片滥用）**：为成片单独建令牌，**仅勾选 `final` 分组**，写入 `.env` 的 `SUBMIT_TOKEN_FINAL`；草稿/日常用 `SUBMIT_TOKEN_DRAFT` / `SUBMIT_TOKEN_STANDARD`。多剧建议按 ProjectKey 拆令牌与额度。

---

## 模板字段说明

- **火山方舟 Key**：写入各火山渠道的 `key`
- **走 seedance-adapter**：Base URL 设为 `http://seedance-adapter:18008`，类型多为 Custom/OpenAI 兼容（适配器侧仍需 `ADAPTER_API_TOKEN`）
- **聚合 Key / Base URL**（可选）：额外创建 OpenAI 兼容兜底渠道，权重低于官方

---

## 安全注意

- `ADMIN_NEWAPI_TOKEN` 具备渠道 CRUD，权限极高：**仅容器环境变量**，禁止预填到 Streamlit 控件
- admin 子域无 basicauth = 公网可改上游 Key → 等同接管计费出口
- 日志/UI 对 key 脱敏；删除需确认渠道名
- 细节见 [`安全审查.md`](./安全审查.md)、[`RULES.md`](./RULES.md)
