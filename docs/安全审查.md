# 对抗性安全审查报告（v0.8.0）

> 威胁模型：互联网攻击者 + 已泄露的低权限团队令牌；入口为腾讯云 VPS 上 Caddy 的 80/443。  
> 审查日期：2026-08-09。C5 起补齐 MinIO 业务用户与 smoke-check；残留见第 4 节。

---

## 1. 结论

v0.4 在端口绑回环、MinIO 私有桶、adapter Bearer、where 转义上有基础，但 **Streamlit 无鉴权 + 密钥预填到浏览器** 是公网上线的最大击穿点。  
v0.4.1 已：去掉 UI 可编辑密钥/Base URL、Caddy 强制 basicauth 模板、MinIO 控制台默认不下公网、adapter fail-closed、成片/ImageUrl 白名单与体积限制、删除预签名 Host 改写兜底。  
v0.4.2 新增 **admin-tool**（可 CRUD New-API 渠道）：`admin.*` **必须** basicauth，且用户与 `team` 分离；`ADMIN_NEWAPI_TOKEN` 仅容器环境、页面不预填。

**在未配置 Caddy basicauth 真实密码前，不要把 submit/dash/admin 解析到公网。**

---

## 2. 发现与处置

| 级别 | ID | 问题 | 处置 |
|------|-----|------|------|
| Critical | C1 | submit 无鉴权 + 侧边栏预填 Token | UI 改为只读 env；Caddyfile `basicauth` |
| Critical | C2 | dash 同上 | 同上 |
| Critical | C2b | admin-tool 可改上游 Key（v0.4.2） | Caddy `admin.*` basicauth（`admin`≠`team`）；Token 仅 env |
| Critical | C3 | 侧边栏改 Base URL → 内网 SSRF | 禁止 UI 改 URL；ComfyUI 仅 env Host |
| High | H1 | MinIO 控制台公网 | Caddy 默认注释 `minio.*` |
| High | H2 | 使用 MinIO root | **C5**：`MINIO_APP_*` 业务用户 + 桶策略；submit/worker 改用 app |
| High | H3 | `ADAPTER_API_TOKEN` 空则放行 | `ADAPTER_REQUIRE_AUTH=true` 默认 |
| High | H4 | 成片 URL 任意下载 SSRF/OOM | https + Host 白名单 + 500MB 上限 |
| High | H5 | ImageUrl 任意外链 | 仅允许公网 MinIO Host（可配白名单） |
| High | H6 | 客户端自选成片档 | 文档强调分档令牌；UI 仍可选 Priority（需运营配单组令牌） |
| High | H7 | `extra_params` 覆盖 payload | adapter allowlist |
| Medium | M1 | 预签名 Host 改写破坏签名 | **已删除**改写兜底 |
| Medium | M2 | ShareUrl TTL 过长 | 默认分享改为 2 天 |
| Medium | M4 | dashboard 无界分页 | `DASH_MAX_PAGES` |
| Medium | M7 | object_prefix 路径穿越 | `sanitize_object_prefix` |

## 3. 上线检查清单（Check）

- [ ] `caddy hash-password` 写入 `deploy/Caddyfile` 的 basicauth（含 **admin** 独立用户）
- [ ] `.env` 中 `ADAPTER_API_TOKEN`、`ADAPTER_REQUIRE_AUTH=true`、`MINIO_APP_PASSWORD`
- [ ] `SUBMIT_MINIO_PUBLIC_ENDPOINT=s3.你的域名`（与 Caddy 一致）
- [ ] 安全组仅 22/80/443；MinIO 控制台仅 SSH 隧道
- [ ] New-API 首登改密；令牌按人限额；**成片用仅 final 分组令牌**（`SUBMIT_TOKEN_FINAL`）
- [ ] `./deploy/smoke-check.sh`（可设 `SMOKE_SUBMIT_URL` 等）→ submit/dash/admin 无凭证 401
- [ ] 预签名 URL 公网可 GET；内网 URL 不可作为 ImageUrl

---

## 4. 残留风险 / 下轮

1. ~~MinIO 业务密钥等于 root~~ → C5 已提供 app 用户（须配置 `MINIO_APP_PASSWORD`）
2. `s3.*` API 面仍对公网（依赖预签名 + 私有桶；需限流/监控）
3. New-API / NocoDB / admin-tool 管理面公网暴露（Caddy 已有 IP 白名单注释模板；建议启用或 SSO∈C9+）
4. Priority→成片：应用层用 `SUBMIT_TOKEN_*` 分档令牌缓解（须运营配置）
5. ComfyUI 专家机自身安全约束；仅配置 `COMFYUI_BASE_URL` Host 可归档
