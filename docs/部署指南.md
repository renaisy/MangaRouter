## 1. 架构与选型

```
团队浏览器 ──HTTPS──► 腾讯云 VPS（Caddy :443）
                          ├─ api.*      → New-API
                          ├─ collab.*   → NocoDB
                          ├─ submit.*   → submit-tool
                          ├─ dash.*     → cost-dashboard
                          └─ s3.*       → MinIO（方舟拉预签名图）
Docker 内：submit → New-API → seedance-adapter → 火山方舟
```

| 项 | 建议 |
|----|------|
| 机型 | ≥ 4 核 8G，系统盘 ≥ 80G；成片多则加数据盘挂载到 `./data` |
| 系统 | Ubuntu 22.04 / 24.04 |
| 安全组 | **只放行 22 / 80 / 443**（不要对公网开放 13000/18080/19000 等） |
| 域名 | 准备 1 个主域 + 上述子域名解析到 VPS 公网 IP |

**不再依赖 ZeroTier 作为主路径。** ComfyUI 仍可跑在专家电脑，需自行保证 VPS 能访问该地址（专线/VPN/安全组白名单）。

---

## 2. 腾讯云准备

1. 购买轻量应用服务器或 CVM，记下公网 IP
2. 安全组入站：TCP 22、80、443
3. DNS：`api` / `collab` / `submit` / `dash` / `admin` / `s3` / `minio` 子域名 A 记录 → 公网 IP
4. （可选）数据盘格式化后挂载到 `/opt/MangaRouter/data`

## 3. 初始化主机

```bash
# 以有 sudo 的用户登录后
cd /opt
sudo git clone https://github.com/renaisy/MangaRouter.git
cd MangaRouter
sudo bash deploy/vps-setup.sh   # 安装 Docker、Caddy、ufw
```

---

## 4. 配置环境变量并启动

```bash
cp .env.example .env
nano .env
```

必改项：
- 所有 `<请改成强随机密码>`
- `VOLC_API_KEY`
- `ADAPTER_API_TOKEN`（与 New-API 渠道密钥一致）
- `MINIO_APP_PASSWORD`（业务用户；submit/worker 用，勿把 root 当日常密钥）
- `SUBMIT_MINIO_PUBLIC_ENDPOINT=s3.your.domain`
- `SUBMIT_MINIO_PUBLIC_SECURE=true`
- `PUBLIC_BASE_URL=https://api.your.domain`
- 推荐：`SUBMIT_TOKEN_FINAL` 仅绑定 final 分组（成片档）

```bash
docker compose up -d
docker compose ps
# 上线烟雾（本机 adapter；公网 basicauth 需设 SMOKE_*_URL）
chmod +x deploy/smoke-check.sh
./deploy/smoke-check.sh
```

服务均监听 `127.0.0.1`，仅本机与 Caddy 可访问。

## 5. Caddy HTTPS 反代

```bash
# 生成密码哈希
caddy hash-password
sudo nano deploy/Caddyfile   # 替换 your.domain 与 basicauth 哈希
sudo cp deploy/Caddyfile /etc/caddy/Caddyfile
sudo systemctl reload caddy
```

**必须**：`submit.*` / `dash.*` / `admin.*` 已配置 basicauth（admin 用户与 team **分开**）。MinIO 控制台默认不对公网——用 SSH 隧道：

```bash
ssh -L 19001:127.0.0.1:19001 user@vps
# 浏览器打开 http://127.0.0.1:19001
```

安全红线与审查结论见 [`安全审查.md`](./安全审查.md)。

## 6. New-API / NocoDB / 适配器

### New-API
1. 打开 https://api.your.domain ，首次用 root 登录后**立即改密**
2. （推荐）在个人设置生成**系统 access_token**，写入 `.env` 的 `ADMIN_NEWAPI_TOKEN` / `ADMIN_NEWAPI_USER_ID`，启动 `admin-tool`，用模板向导一键建三档渠道——见 [`管理员配置手册.md`](./管理员配置手册.md)
3. 或手动创建渠道：Base URL 填 `http://seedance-adapter:18008`（Docker 内网）
4. 渠道密钥 / 请求头带 `Authorization: Bearer <ADAPTER_API_TOKEN>`（与 `.env` 一致）
5. 建 `draft` / `standard` / `final` 三个分组，按 [`New-API渠道配置.md`](./New-API渠道配置.md) 绑模型
6. 创建令牌：草稿/日常/成片建议拆令牌；成片仅勾选 `final`，写入 `SUBMIT_TOKEN_*`；多剧按 ProjectKey 拆额度。填入后 `docker compose up -d submit-tool submit-worker`
7. 提交时 **ProjectKey 必填**；对象落在 `projects/{ProjectKey}/...`

### NocoDB
1. https://collab.your.domain 注册管理员（已 invite-only）
2. 建空 Base，记 `baseId`
3. 生成 API Token
4. 在仓库目录执行：
   ```bash
   docker compose run --rm -e NOCODB_BASE_URL=http://nocodb:8080 \
     -e NOCODB_TOKEN=xxx -e NOCODB_BASE_ID=p_xxx \
     --entrypoint python cost-sync /dev/null 2>/dev/null || true
   # 推荐直接在主机：
   pip install httpx && cd nocodb-init
   python init_schema.py --base-url https://collab.your.domain --token xxx --base-id p_xxx
   ```
5. 把 Storyboards / Costs 的 tableId 写入 `.env`，重启 `submit-tool` / `submit-worker` / `cost-sync` / `cost-dashboard`

### 图传说明
上传图会写入 MinIO，并生成 **s3.your.domain 上的预签名 URL** 交给方舟拉取。请确认公网可：
`curl -I "https://s3.your.domain/minio/health/ready"`（或对预签名 URL 做 GET）。

## 7. 验证全流程

1. 文生视频：submit 标准提交 → NocoDB 出现 `running` → worker 回填 `succeeded` + `MinioPath`
2. 首帧：上传图后任务成功（方舟能拉预签名 URL）
3. 批量：Storyboards 填 `pending` → 批量提交 → 归档到 `outputs/`
4. 成本：次日或手动 `docker compose exec cost-sync python sync.py --days 1` → 看板有数

## 8. 日常运维与备份

```bash
docker compose logs -f new-api
docker compose pull && docker compose up -d
```

备份脚本：

```bash
sudo bash deploy/backup.sh          # 打 tar 到 /var/backups/mangarouter/
# 可选：上传到腾讯云 COS（需先装 coscli 并配置）
```

建议每日 cron：`0 3 * * * /opt/MangaRouter/deploy/backup.sh`

**恢复演练**：至少做一次解压 `data/` 后 `docker compose up -d`，记录 RTO。

## 9. 无域名临时方案

仅用于验收：可用 [`deploy/nginx.conf.example`](../deploy/nginx.conf.example) 做 HTTP 反代，安全组临时放行 80。

限制：
- 无 HTTPS，勿长时间公网裸奔
- MinIO 预签名 Host 与公网 IP 对齐困难，图生视频可能失败——**尽快上域名 + Caddy**
